<!-- global agent rules for chat and repository writing -->

COMMUNICATION IN CHAT
- use chinese as natural language for all chat
- never use markdown tables in conversation
- follow IRC style with short, direct, one topic per message
- prefer bullet lists over long paragraphs
- use simple and clear wording

WRITE AND EDIT AT REPO
- use english for all natural language text in git repositories
- write commit messages, code comments, and document text in english
- keep comments using simple english words
- follow existing project coding conventions

WRITING STYLE
- read `.agent/rule/core/agent/writing-style.rule.md` for text rules
- read `.agent/rule/core/agent/writing-structure.rule.md` for document blocks
