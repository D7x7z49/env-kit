<!-- text rules for code comments, messages, rules, and documents -->

CASE
- use lowercase for code comments, messages, and rule text
- keep the conventional case of abbreviations and proper names
- use sentence case in user-facing documents such as `README.md`
- use lowercase and `/` in file header paths

DELIMITERS
- use commonmark inline code for a path, command, or symbol
- wrap a value inside a message in square brackets
- wrap an external reference in angle brackets
- use parentheses for supplementary information

PROSE
- write in natural english word order
- use prepositions to connect context to values
- end a complete statement with a period
- omit the trailing period on list items, short notes, and fragments
